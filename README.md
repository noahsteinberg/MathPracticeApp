# Math Practice App

A React and TypeScript math-practice application for children ages 7-12.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run format:check
npm test
npm run build
```

Requirements and the phased checklist are in [docs/specification.md](docs/specification.md) and [docs/TODO.md](docs/TODO.md).
